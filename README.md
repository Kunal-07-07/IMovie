# IMovie 🎬

IMovie is a movie booking web application built using the MERN stack.

## Features
- Browse movies
- View movie details
- User authentication
- Movie booking
- Seat selection
- Checkout interface

## Technologies Used
- React.js
- Node.js
- Express.js
- MongoDB
- JavaScript
- CSS

## Project Structure
- `frontend/` — Frontend application
- `backend/` — Backend application

## Installation
1. Download or clone the repository.
2. Run `npm install` in the frontend directory.
3. Run `npm install` in the backend directory.
4. Configure your environment variables.
5. Start the frontend and backend servers.
